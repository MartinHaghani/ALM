# Execution-plan archive

Purpose: route active and completed work without duplicating plan contents.

- [Active plans](active/) are living implementation records and appear as concise
  links in [PROJECT_STATE.md](../PROJECT_STATE.md).
- [Completed plans](completed/) preserve final outcomes, decisions, and validation
  after implementation is reconciled with issues, commits, and stable docs.

Create plans from [the canonical template](../templates/exec-plan.md) and follow
[the repository planning policy](../../PLANS.md).
